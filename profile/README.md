## 📬 Need something? Raise a request

All requests are tracked in the **[Project DevOps Requests](https://github.com/orgs/ConnectifiedAus/projects/5)** board.

To create a request:

1. Open **[Project DevOps Requests](https://github.com/orgs/ConnectifiedAus/projects/5)**
2. Add a new item and give it a clear, descriptive title
3. Choose the request type and fill in as much detail as possible
4. Submit — the team will triage and pick it up

### Request types

| Type | Use it for |
| --- | --- |
| 📝 **Request** | Asking for something new or a change, such as access, accounts, licences, Azure resources, Office 365 changes or deployments |
| 🚨 **Incident** | Something is broken, down or not working as expected, such as outages, errors, failed deployments or access suddenly lost |

> 💡 **Tip:** The more context you provide (environment, urgency, screenshots, error messages), the faster we can help.
